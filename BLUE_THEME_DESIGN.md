## 🔧 Technical Details

### CSS Variables Used
All color values use CSS variables for easy customization:
```css
--primary-color: #0ea5e9
--accent-primary: #0ea5e9
--accent-secondary: #38bdf8
```

### Easy to Customize
To change colors, edit variables in `src/App.css`:
```css
:root {
  --primary-color: #0ea5e9;      /* Change primary color */
  --accent-primary: #0ea5e9;     /* Change accent color */
}
```
