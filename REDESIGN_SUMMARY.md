## 🎨 Color Customization

Want to adjust colors? Edit `src/App.css`:

```css
:root {
  /* Change these values to customize colors */
  --primary-color: #0ea5e9;        /* Primary accent */
  --accent-primary: #0ea5e9;       /* Main accent */
  --accent-secondary: #38bdf8;     /* Secondary accent */
  --bg-primary: #0f1419;           /* Main background */
  --bg-secondary: #1a1f2e;         /* Card backgrounds */
}
```

All sections update automatically!
